# 12. Бар «Эль Фароль» (`el-farol`)

Основа: Arthur W. B. (1994). *Inductive Reasoning and Bounded Rationality*. American Economic Review, 84(2),
406–411. Игра меньшинства: Challet D., Zhang Y.-C. (1997). *Emergence of cooperation and organization in an
evolutionary game*. Physica A, 246, 407–418.

## Карточка

```js
{
  id: 'el-farol',
  name: 'Бар «Эль Фароль»',
  category: 'econ',
  teaser: 'Если все принимают решение по одним и тем же данным, эти данные перестают работать.',
  players: '5+',
  time: '12 мин',
  structure: 'solo',
}
```

## Параметры

| Константа | Значение | Комментарий |
|---|---|---|
| `THRESHOLD` | 60% | порог: мест хватает, если пришло **не больше** `floor(0.6 × N)` |
| `ROUNDS` | 8 | |
| `TALK_FROM_ROUND` | 5 | с раунда 5 можно договариваться вслух |
| `PAY_GOOD` | +1 | пришёл, мест хватило |
| `PAY_CROWD` | −1 | пришёл, толпа |
| `PAY_HOME` | 0 | остался дома |
| `ROUND_TIMER_SECONDS` | 10 | быстро, на ощущении |

Места на проекторе: `{capacity} мест` при N игроках (например, N = 8 → 4 места; N = 10 → 6 мест).
В разборе показывается «идеальная» посещаемость = capacity каждый раунд.

## Механика

1. Каждый раунд каждый тайно решает: **Иду / Дома**.
2. Проектор: сколько пришло / сколько мест, «уютно» 🟢 или «толпа» 🔴, **история всех прошлых раундов** (столбики).
3. Раунды 1–4 молча. Перед раундом 5 ведущий объявляет: «Теперь можно договариваться». Договорённости
   ни к чему не обязывают.
4. После 8 раундов — очки каждого (сумма) и график посещаемости с линией порога.

Ожидаемая динамика: без разговоров посещаемость колеблется вокруг порога, «уютных» вечеров мало, и часто
после уютного вечера следует толпа (все решили «вчера было хорошо — пойду»). С разговорами команда обычно
изобретает **расписание** («нечётные раунды — первая половина списка»), и посещаемость стабилизируется.

## Экраны (`ROUND_TITLES`)

1. `Бар «Эль Фароль» — правила`
2. `Раунд {n} из 8: кто идёт?` (ввод: переключатель по каждому участнику)
3. `Вечер {n}` (проектор: пришло X из capacity + история)
4. Перед раундом 5: `Теперь можно договариваться`
5. `Что получилось у вашей команды` (график посещаемости 1–8, линия порога, закрашены «толпа»/«уютно»; сравнение раундов 1–4 и 5–8)
6. `Бар «Эль Фароль»` (контекст + факты)

## Разбор (`reveal-copy.js`)

Входные данные: `{ attendance: number[], capacity, goodSilent, goodTalk, spreadSilent, spreadTalk }`
(`spread` — среднее абсолютное отклонение посещаемости от capacity в половине игры).

- **what**: «Сколько вечеров из восьми прошли «уютно» (пришло не больше мест) без договорённостей и с ними, и насколько сильно посещаемость отклонялась от числа мест.»
- **read**: «Без разговоров посещаемость обычно колеблется вокруг порога: после уютного вечера приходят все, после толпы все сидят дома. Если с договорённостями отклонение уменьшилось, команда заменила угадывание координацией.»
- **verdict**:
  - голова: `Посещаемость: {attendance.join(' · ')} при {capacity} местах. Уютных вечеров: {goodSilent} из 4 молча и {goodTalk} из 4 с договорённостями.`
  - хвост:
    - spreadTalk < spreadSilent − 0.5: « Договорённость сработала: посещаемость стала ровнее.»
    - spreadTalk ≥ spreadSilent: « Даже договорившись, команда не смогла выровнять посещаемость: обещания нарушались или расписания не было.»
    - иначе: « Разница между половинами игры небольшая.»

## Вопросы для ретро

- Какие наши «бары»: общие ресурсы с ограниченной ёмкостью (стенд, ревьюеры, окно деплоя, переговорки)?
- Где мы полагаемся на то, что «само распределится», хотя простое расписание решило бы проблему?

## Как решено при реализации

- Быстрый ввод: по умолчанию все «Дома», ведущий нажимает «Иду» у тех, кто идёт.
- Очки — только в конце (итоговая таблица), по ходу игры на проекторе лишь история посещаемости.
