# 9. Угадай ⅔ от среднего (`beauty-contest`)

Основа: Nagel R. (1995). *Unraveling in Guessing Games: An Experimental Study*. American Economic Review, 85(5),
1313–1326. Идея — Keynes J. M. (1936). *The General Theory of Employment, Interest and Money*, гл. 12.

## Параметры

| Константа | Значение | Комментарий |
|---|---|---|
| `MIN`, `MAX` | 0, 100 | целые числа |
| `P` | 2/3 | |
| `ROUNDS` | 4 | как у Нагель |
| `ROUND_TIMER_SECONDS` | 30 | |
| Победитель | ближайший к `P × среднее` | при ничьей побеждают все ближайшие |

### Уровни рассуждения (линии на гистограмме)

| Уровень | Логика | Число |
|---|---|---|
| 0 | «наугад / в среднем 50» | 50 |
| 1 | «все назовут в среднем 50 → ⅔ × 50» | 33 |
| 2 | «все думают на шаг → ⅔ × 33» | 22 |
| 3 | | 15 |
| 4 | | 10 |
| ∞ | равновесие Нэша | 0 |

Классификация ответа для разбора: ближайший уровень в пределах ±3, иначе «вне уровней».
Числа > 67 отдельно помечаются как **«невозможно выиграть»** (⅔ от максимально возможного среднего = 66,7).

## Экраны (`ROUND_TITLES`)

1. `Угадай ⅔ от среднего — правила`
2. `Раунд {n} из 4: впишите число каждого`
3. `Итог раунда {n}` (проектор: гистограмма 0–100 с линиями уровней, среднее, ⅔ среднего, победитель по имени)
4. `Что получилось у вашей команды` (разбор: сползание ⅔ среднего по раундам + уровни в раунде 1)
5. `Угадай ⅔ от среднего` (контекст + факты)

## Разбор (`reveal-copy.js`)

Входные данные: `{ targetByRound: number[], meanByRound: number[], levelsR1: { l0, l1, l2, l3plus, zero, impossible } }`

- **what**: «Как менялось ⅔ от среднего от раунда к раунду и на каком шаге рассуждения остановилась команда в первом раунде.»
- **read**: «Уровень 1 — около 33, уровень 2 — около 22, дальше к нулю. Чем быстрее число сползает к нулю, тем быстрее команда учится предсказывать друг друга. Числа больше 67 выиграть не могут в принципе.»
- **verdict**:
  - голова: `⅔ от среднего: {targetByRound.join(' → ')}. В первом раунде на уровне 1 было {l1} чел., на уровне 2 — {l2}, назвали 0 — {zero}.`
  - хвост:
    - targetR1 ≤ 15: « Команда с первого раунда мыслила глубоко — почти как теоретики игр.»
    - targetR4 < targetR1 / 2: « Классическое сползание: за четыре раунда команда научилась думать на несколько шагов вперёд.»
    - иначе: « Числа почти не сползали: команда держалась своего уровня рассуждений.»
  - добавка при `impossible > 0`: ` {impossible} чел. назвали число больше 67 — его нельзя выиграть ни при каком раскладе.`

## Вопросы для ретро

- На каком «шаге» мы обычно останавливаемся, когда прогнозируем реакцию пользователей, стейкхолдеров, соседних команд?
- Где мы угадываем, что решат другие, вместо того чтобы спросить?

## Как решено при реализации

- Имя победителя раунда показывается на проекторе (в итоге раунда) и в итоговой таблице «кто сколько раундов выиграл».
- Вариант с P = ½ не сделан: только ⅔.
