## Где что лежит в коде

| Раздел файла | В коде |
|---|---|
| Карточка | `GAMES` в `src/state.js`; иконка — `src/icons/*.png`, её цвет — `ICON_COLORS` в `src/map-render.js` |
| Параметры, формулы, баланс | `src/logic/<id>.js` (чистые функции, юнит-тесты — `test/unit/<id>.test.js`) |
| Экраны | `src/games/<id>.js` (`ROUND_TITLES` и секции `round-N`) |
| intro / context / facts | `src/content/<id>.json` (+ `rules` и `announcement`) |
| Разбор (reveal) | функция в `src/reveal-copy.js` |
| Сообщения в личку | функции `*Message` в `src/logic/<id>.js`, показываются блоком «Раздача» (`src/dispatch.js`) |
| e2e-сценарий | объект в `test/games.js` (smoke, persistence, export, a11y, проектор) и строка в `CHARTS` в `test/charts.spec.js` |

## Что добавилось при реализации (по сравнению с фактурой)

- **Правила для игроков на первом экране** — `rules` в JSON (2–3 правила + ход игры), рендер `renderRules`,
  идут на проектор. Появились у всех 21 игры, не только у новых: раньше зал слышал правила только голосом ведущего.
  Шаги `intro.steps` так и остались репликами ведущего.
- **Сводка прошлого раунда видна залу** (`.round-recap` на проекторе, только агрегаты, без имён): «Слабое
  звено», «Кто возьмёт на себя», «Лимоны», «Угадай ⅔» — и заодно старое «Общественное благо».
- **Итоговая таблица «кто сколько набрал»** (`src/leaderboard.js`) — во всех новых играх с личными очками
  («Слабое звено», «Кто возьмёт на себя», «Лимоны», «Угадай ⅔» — по победам, «Эль Фароль», «Аукцион») и в старых
  «Дилемме заключённого» и «Ультиматуме». Нет в «Скрытом профиле» (там общее решение) и в «Пивной игре»
  (счёт общий на цепочку).
- **Табло аукциона** на проекторе: лидер, второе место, «аукционист в плюсе/минусе» и последние 6 ставок.
- **Ростер на проекторе** при 3+ группах (пары, звенья цепочки) — сеткой, число человек отдельной строкой.
- **Эталон пивной игры** считается движком при загрузке модуля (384) и закреплён юнит-тестом.
- **Короткая главная цифра** («4 → 6» вместо всей цепочки раундов) там, где длинная не помещалась на проектор;
  полная цепочка — в разборе.
- Блока «Вопросы для ретро» в коде нет: он остался в файлах как материал для ведущего.

## 🔒 Раздача в личку

«Скрытому профилю», «Лимонам» и «Пивной игре» нужно тайно передать конкретному человеку его информацию:
досье, качество машины, сводку по складу. На экране ведущего (**никогда не на проекторе**) — блок «Раздача»:

```
РАЗДАЧА · РАУНД 2                                          Отправлено: 1 из 4
Аня     Продавец · лот 3    ▸ Текст сообщения              [✓ Отправлено]
Борис   Продавец · лот 1    ▸ Текст сообщения              [Копировать]
Вика    Покупатель          — ничего не отправлять —
```

- Одна строка на участника: имя, роль, готовый текст (plain text — сразу для Telegram, Slack и т. п.; раскрывается
  по клику) и «Копировать». Скопированная строка получает ✓; отметки сбрасываются на следующем раунде/неделе.
- Сообщение самодостаточно: название игры, раунд и что ответить ведущему.
- Тексты сообщений для каждой игры — в разделе «🔒 Сообщения в личку» её файла.

## Проверка фактов

Все цифры и истории проверены по первоисточникам или надёжным вторичным источникам (сентябрь 2026).
Что пришлось исправить или убрать, указано в разделе «Источники» каждого файла.
